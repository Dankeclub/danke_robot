# 项目定位

> 广和通 AIoT 赛道 · SC171 V3 平台 · 儿童陪护 + 辅助教育

## 赛题匹配

本作品对应广和通 AIoT 赛道 **开放命题**，命中赛题推荐的 **儿童陪护**（情感陪伴 / 教育陪伴 / 安全监护 / 非接触式健康监测）与 **辅助教育**（自学辅助 / 习惯培养 / 姿势评判 / 智能评估）两个方向。

赛题要求终端同时具备 **感知 + 计算 + 通信** 三项能力，并通过端云结合满足 **实时性、安全性、隐私性、流畅度、准确性** 五维品质。本系统以 SC171 V3 为唯一主控平台，所有核心能力均在赛题平台上闭环实现。

---

## 痛点与场景

面向 3-8 岁儿童家庭学习场景，解决四个典型问题：

1. **家长无法长期陪伴** — 双职工家庭中，课后学习陪伴严重依赖平板/音箱等被动设备。**→ 机器人主动介入学习过程，家长端实时行为推送，让远程陪伴不只是事后看报告。**
2. **固定设备只能看不能动** — 摄像头只能观察，无法主动介入学习场景。**→ 麦轮全向移动 + 自主寻找/跟随，打破固定安装的空间限制。**
3. **行为数据零散** — 缺乏跨时间、跨空间的结构化学习行为记录。**→ 多房间持续感知 + 结构化事件流，形成连贯的长期行为数据。**
4. **设备被动交互** — 现有学习终端"等孩子点击 → 返回结果"，无法根据状态主动调整。**→ 行为驱动主动介入，不等待用户指令。**

由此设计一套融合 **边缘智能 + 移动机器人 + 端云协同 + 多模态行为感知** 的自主陪伴机器人系统。

## SC171 平台深度利用

| 平台能力 | 利用方式 | 对应系统功能 |
|-----------|---------|-------------|
| 13 TOPS NPU | YOLOv8n 人体检测 + MediaPipe Pose 姿态识别，320×320 输入下 15 FPS 端侧推理 | 行为感知 |
| 8 核 Cortex@2.7GHz | 几何规则分类器 + 时间窗口滤波 + 决策引擎，单帧 <2ms | 行为决策 |
| 8GB RAM + 128GB 存储 | 端侧全闭环运行，离线可用；六大学习模块本地部署 | 全系统 |
| GPIO×4 | 四路电机直驱，PWM 信号 50Hz 控制周期，同步更新 | 运动控制 |
| UART | 两路 HC-SR04 超声波传感器，3.3V 逻辑电平直连 | 安全避障 |
| USB | 广角摄像头 (1280×720@30fps) + ReSpeaker 4-Mic 环形麦克风阵列 | 感知输入 |
| HDMI | 7 寸 IPS 触摸屏 (1024×600)，六学习模块交互界面 | 人机交互 |
| PWM | 3×WS2812 RGB LED 灯带，8 种动态效果表达机器人状态 | 状态反馈 |

| Fibo AI Stack | PyTorch → ONNX → NPU 部署工具链，YOLOv8n 端侧模型部署 | AI 部署 |

> 关键决策：选择 SC171 而非通用单板计算机，核心原因是其 NPU 算力使视觉推理可在端侧实时闭环运行，从架构层面保障了行为感知的低延迟和家庭场景的隐私安全。这是赛题"本地计算 + 云端算力"理念的直接体现。

## 系统全景：AIoT 三角架构

系统整体采用 **端云协同** 架构，以赛题要求的 **感知 → 计算 → 通信** 三角模型组织：

```text
                  ┌──────────────────────────────┐
                  │      感  知  层               │
                  │  · USB 广角摄像头              │
                  │  · ReSpeaker 4-Mic 阵列       │
                  │  · 2×HC-SR04 超声波            │
                  │  · 7 寸触摸屏（触控输入）        │
                  └──────────────┬───────────────┘
                                 │
                  ┌──────────────▼───────────────┐
                  │      计  算  层（SC171 V3）    │
                  │                               │
                  │  NPU (13 TOPS):               │
                  │  · YOLOv8n 人体检测 15 FPS      │
                  │  · MediaPipe Pose 33 关键点     │
                  │                               │
                  │  CPU (8×Cortex@2.7GHz):       │
                  │  · 几何规则分类器 2ms/帧         │
                  │  · 决策引擎 + 运动控制 50Hz      │
                  │                               │
                  │  全链路端侧闭环，原始帧推理后丢弃   │
                  └──────────────┬───────────────┘
                                 │
                  ┌──────────────▼───────────────┐
                  │      通  信  层               │
                  │  · WebSocket → 行为数据上报    │
                  │  · RTMP → 视频推流             │
                  │  · REST API → 数据查询         │
                  │  · HTTPS + TLS 传输加密       │
                  └──────────────────────────────┘
```

### 软件模块划分

计算层的软件系统按功能划分为四大模块，按感知→决策→执行的数据流组织：

| 模块 | 核心职责 | 关键输出 |
|------|---------|---------|
| **行为感知** | YOLOv8n 人体检测 → MediaPipe Pose 姿态识别 → 几何规则分类器 + 时间窗口滤波 | 结构化行为事件（站/坐/躺/走 + 坐姿质量 + 用眼距离） |
| **行为决策与陪伴执行** | 规则引擎接收行为事件，生成陪伴指令；端侧直出路径处理时效性提醒，云端路径处理知识问答 | 语音指令、电机驱动值、灯光效果 |
| **云端数据分析与家长端** | Kimi LLM 知识问答 + 行为数据聚合分析 + 家长端实时视频看板 + 微信小程序 | 成长画像、AI 周报、实时视频流 |
| **端云通信** | WebSocket 行为数据上报与指令转发 + RTMP/HTTP-FLV 视频流 + REST API 数据查询 | 端云双向数据通道 |

> 四大模块环环相扣：感知模块输出行为事件 → 决策模块生成陪伴指令 → 执行通道输出语音/移动/灯光 → 端云通道将结构化行为数据上报 → 云端聚合为成长画像 → 家长端小程序呈现。

### 端/云/小程序三层分工

| 层 | 载体 | 职责 | 约束 |
|----|------|------|------|
| 边缘端 | SC171 V3 机器人 | 实时感知 + 实时决策 + 实时执行 + 视频推流 | 毫秒级闭环，离线可用 |
| 云端 | 应用服务器 | 复杂语义对话 (Kimi LLM) + 定时任务调度 (OpenClaw) + 长周期数据分析 + AI 周报生成 | 不参与实时控制，不存储原始视频帧 |
| 用户端 | 车载屏 + 微信小程序 | 学习交互 + 家长实时看护 + 行为看板 + 远程互动 | 小程序所有传输加密 |

> **OpenClaw 说明**：OpenClaw 部署在云端，负责家长定时学习任务的调度——家长通过小程序创建"每天下午 4 点口算练习"等任务后，OpenClaw 到点通过 WebSocket 网关向 SC171 车载屏推送执行指令。所有行为感知的原始视频帧仍在 SC171 NPU 推理后即时丢弃，不上传、不落盘，从架构层面保障隐私。

## 五大核心能力

> 五大能力层层递进：机器人先**自主寻找**儿童，然后**持续跟随**，在此过程中**感知行为状态**，积累形成**成长画像**，最终通过**双向情感互通**让家长参与进来——从"设备找人"到"感知积累"到"人连接人"的完整闭环。

### ① 自主寻找儿童

机器人在家庭环境中自主巡航，当视野内未检测到目标儿童时，主动搜索儿童位置，发现后自动靠近并进入陪伴状态。

| 项 | 值 |
|----|-----|
| 巡航方式 | 麦轮全向移动，沿空间边界扫描 |
| 检测手段 | NPU 端侧人体检测 15 FPS，无需联网 |
| 核心突破 | 从"等孩子来找设备"变为"设备主动找孩子" |
| 赛题对应 | 感知（人体检测）→ 计算（NPU 推理）→ 通信（无网络依赖，端侧闭环） |

---

### ② 主动跟随陪伴

学习过程中，当儿童移动至其他区域时，机器人持续跟随，保持适当陪伴距离，在不同房间之间保持连续陪伴。

| 项 | 值 |
|----|-----|
| 跟随方式 | 人体检测框位置驱动 PID 控制 |
| 运动能力 | 麦轮逆运动学解算，前进/后退/平移/原地旋转 |
| 控制频率 | 50Hz，四路 PWM 同步更新 |
| 速度上限 | 0.3 m/s（安全限速） |
| 核心突破 | 不依赖固定安装，真正的移动陪伴 |

---

### ③ 多模态行为感知

融合视觉、姿态、距离、音频、触控五类感知通道及灯光一类状态表达通道，对儿童学习状态进行实时分析，输出结构化行为事件供决策引擎使用。

| 通道 | 传感器 | 输出 |
|------|--------|------|
| 视觉 | USB 广角摄像头 → NPU YOLOv8n | 人体位置 + 边界框 |
| 姿态 | MediaPipe Pose 33 关键点 → 几何分类器 | 站/坐/躺/走 + 坐姿质量 + 用眼距离 |
| 距离 | 2×HC-SR04 超声波 | 前方障碍物 + 儿童安全距离 |
| 音频 | ReSpeaker 4-Mic 阵列 → 云端 ASR | 语音指令识别 |
| 触控 | 7 寸触摸屏 | 学习模块交互输入 |
| 灯光 | 3×WS2812 LED（输出通道） | 8 种状态表达（非语音反馈） |

> 行为分类准确率 **85%**（站/坐/躺/走四类，实测条件：单儿童、室内正常光照、正脸朝向摄像头，测试集约 2000 帧标注样本）。时间窗口滤波将虚假行为事件控制在 **≤1 次/30 分钟**（同条件连续监控测试）。

### ④ 多房间成长画像

结合空间位置与行为数据，建立儿童在不同学习环境中的长期行为模型，自动生成成长报告。

| 分析维度 | 内容 |
|----------|------|
| 房间对比 | 客厅 vs 卧室专注度差异 |
| 时间趋势 | 不同时段学习效率变化 |
| 长期变化 | 跨周/跨月行为趋势 |
| 习惯养成 | 学习习惯形成与退化分析 |
| AI 周报 | 基于当周行为数据自动生成自然语言报告 |

### ⑤ 双向情感互通

将机器人感知到的行为事件实时推送至家长端，家长可即时回应（表情/语音/任务），形成从"孩子行为 → 机器人感知 → 云端推送 → 家长响应 → 机器人传递 → 孩子感受"的完整双向闭环。

| 项 | 值 |
|----|-----|
| 推送通道 | WebSocket 长连接，结构化的实时行为事件 |
| 家长回应 | 表情 / 语音 / 学习任务，经云端网关直达 SC171 |
| 端到端延迟 | <100 ms（同城 4G/WiFi 条件下实测，家长发送 → 机器人屏幕显示） |
| 任务发布 | 家长通过小程序创建定时学习任务，由云端 OpenClaw 到点调度，经 WebSocket 推送至 SC171 车载屏 |
| 核心突破 | 不是单向监控，是双向情感连接 |

## 核心创新点

**创新一：SC171 NPU 端侧实时行为感知闭环。** 13 TOPS NPU 运行 YOLOv8n + MediaPipe Pose，配合 CPU 几何规则引擎，实现"感知 → 决策 → 执行"全链路端侧毫秒级闭环。Fibo AI Stack (PyTorch → ONNX → NPU) 部署工具链使端侧实时推理具备工程可行性。从架构层面保障家庭隐私——原始视频帧推理后即时丢弃，不落盘不上传。

**创新二：行为驱动的主动陪伴交互范式。** 区别于传统学习设备"等待指令 → 单次响应"的被动模式，机器人以持续行为感知为基础，在坐姿纠正、走神唤回、疲劳提醒、正向鼓励等节点主动介入，将机器人从执行工具变为陪伴伙伴。时效性强的提醒走端侧直出路径（毫秒级），复杂知识问答走云端 LLM 通道——两条路径由决策引擎统一调度。

**创新三：多模态融合的儿童行为感知链路。** 视觉（人体检测 + 姿态估计 + 用眼距离估算）+ 超声（障碍物与距离）+ 触控（学习交互）+ 灯光（状态表达）——五通道多模态感知融合。行为分类采用可解释的几何规则而非黑箱网络，每个中间结果可追溯，阈值可调参，跨环境泛化一致。

**创新四：SC171 边缘端 + 云端 + 家长端三端协同架构。** SC171 承担全部实时推理与行为决策，云端仅处理 LLM 对话、OpenClaw 定时任务调度和长周期数据分析，两端之间仅传输结构化行为数据。家长端将数据转化为家长可感知的成长报告和即时互动通道，打通"孩子在学什么、学得怎么样"的信息缺口。

## 已知局限

> 以下局限均来自原型验证阶段的实测观察，在正式参赛文档中如实呈现，展示工程思维的完整性。

| 局限 | 说明 | 影响范围 |
|------|------|---------|
| 单摄像头人体检测无身份区分 | 当前 YOLOv8n 仅做人体检测，不做人脸识别，多儿童或成人同框时无法区分个体 | 多子女家庭场景下行为数据可能混淆 |
| 超声波避障存在死角 | 2 路 HC-SR04 仅覆盖前方扇形区域，后方和侧面无传感器覆盖 | 后退或平移时需人为监护 |
| YOLOv8n + MediaPipe Pose 双模型串行推理 | 当前为串行流水线，未做 NPU 并行调度优化；MediaPipe Pose 在 CPU 上运行 | NPU 存在空闲等待，理论帧率可进一步提升 |
| 几何规则对极端姿态敏感 | 儿童趴地、蜷缩、背对摄像头等姿态下关键点检测失效 | 异常姿态下行为分类暂停，决策模块退入保守模式 |
| 端侧 LLM 未实际部署 | SC171 预适配 1.5B 模型已验证可行性，但当前系统仍走云端 Kimi LLM | 离线场景下无知识问答能力 |
| 用眼距离估计依赖正脸 | 正脸时误差约 ±5cm，侧脸时切换为肩宽替代，误差升至 ±10cm | 侧脸/背对时用眼距离提醒精度下降 |

## 可扩展方向

- **端侧大模型离线对话**：SC171 预适配 DeepSeek-Qwen2.5-1.5B / Qwen3-1.7B，配合端侧 ASR+TTS 可实现全离线语音交互。当前架构中复杂对话走云端 Kimi LLM，端侧模型可作为离线降级方案或未来演进方向。
- **多儿童独立画像**：利用 NPU 剩余算力部署轻量人脸识别，为多子女家庭建立独立成长画像
- **自主回充**：低电量自动返回充电座
- **房间级空间感知**：视觉地标识别实现精确房间定位，使行为分析具备更细粒度的空间上下文
