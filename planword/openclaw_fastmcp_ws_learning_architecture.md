# 基于 OpenClaw Cron + FastMCP + WebSocket 的定时自动助学方案

## 1. 目标

本方案用于实现“家长通过语音在前端或小程序创建定时学习任务，到点后自动唤起孩子的学习页面，并在学习完成后回写结果”的自动化流程。

系统需要同时支持：

- 家长在 **Vue3 前端** 发起学习指令
- 家长在 **微信小程序** 发起学习指令
- 家长通过 **语音输入 + ASR** 发起学习指令
- 使用 **OpenClaw 的 cron/job 调度能力** 管理定时任务
- 使用 **OpenClaw agent loop** 作为任务执行入口
- 使用 **FastMCP** 封装学习动作工具
- 使用 **自建 WebSocket（WS）推送层** 将指令实时下发到小朋友学习前端
- 学习页面打开成功后立即回执
- 学习完成后或是页面退出时再写回后端状态，形成完整学习记录
注意所有接口和json字段只是模拟过程，具体使用还需要与用户详细讨论！！！！
---


## 2. 设计原则

1. **OpenClaw 只负责定时调度与触发，不负责前端实时消息分发。**
2. **FastMCP 只负责动作编排与工具出口，不直接承担浏览器长连接管理。**
3. **WebSocket 只负责实时推送与在线会话路由，不负责任务编排（在fastmcp中维护全局ws客户端状态，保持长连接）。**
4. **业务后端负责统一状态管理、任务落库、学习记录写回与审计。**
5. **学习“打开成功”和“学习完成”必须拆成两个状态。**
6. **所有定时任务都必须带幂等 ID，避免重复触发导致重复打开页面。**

## 3. 术语定义与边界

### 3.1 OpenClaw Cron / Job

**定义：**
OpenClaw 提供的定时调度能力，用于在指定时间触发任务执行。

**职责边界：**
- 接收并保存家长创建的定时任务
- 按时间到点触发
- 唤醒 agent loop
- 记录触发历史、运行状态与执行结果

**不负责：**
- 不直接操作前端页面路由
- 不直接维护浏览器 / 小程序的 WS 在线连接
- 不直接处理学习完成的业务逻辑

---

### 3.2 OpenClaw Agent Loop

**定义：**
OpenClaw 在任务触发后启动的一次完整执行循环，用于读取任务、组装上下文、调用工具、处理结果并保存状态。

**职责边界：**
- 读取 cron 触发后的任务上下文
- 调用 FastMCP 工具
- 等待工具回执
- 将执行结果写回 OpenClaw 运行记录

**不负责：**
- 不直接持有长期实时连接
- 不直接推送 UI 跳转指令到前端
- 不负责课程内容本身的教学逻辑

---

### 3.3 FastMCP

**定义：**
一种用于对外暴露 MCP 工具的服务层，本方案中它负责把“打开课程页”“通知开始学习”“上报结果”等动作封装成可调用工具。

**职责边界：**
- 作为工具编排层
- 将上层任务翻译成结构化动作
- 向自建 WebSocket 推送层发送内部 JSON 指令

**不负责：**
- 不承担前端页面的路由跳转
- 不承担全局 WS 连接池维护
- 不承担任务调度本身

---

### 3.4 WebSocket（WS）推送层

**定义：**
由业务方自建的实时消息通道，负责维护在线会话并向 Vue3 或小程序推送指令。

**职责边界：**
- 维护全局 WS 连接
- 识别当前在线用户、设备或会话
- 接收 FastMCP 发来的内部 JSON
- 将消息推送到目标前端
- 接收前端 ack 与状态回执

**不负责：**
- 不负责定时调度
- 不负责生成学习任务
- 不负责课程业务状态的最终落库

---

### 3.5 ASR

**定义：**
Automatic Speech Recognition，语音识别服务。用于将家长语音转成文本。阿里接口

**职责边界：**
- 把音频转为文本
- 输出识别结果
- 为调用openclaw提供文本输入

**不负责：**
- 不负责判断业务意图
- 不负责创建任务
- 不负责调用 OpenClaw

---

### 3.6 意图识别 / 语义结构化（openclaw背后对接的llm负责，不需要代码设计）

**定义：**
将家长语音或文本转换为结构化任务参数的过程。

**职责边界：**
- 从自然语言中抽取课程类型、时间、重复规则、孩子 ID、页面路由等字段
- 生成标准化任务对象

**不负责：**
- 不直接执行任务
- 不直接保存定时器
- 不负责页面跳转

---

### 3.7 Vue3 前端

**定义：**
家长端或孩子端的网页应用，用于展示任务、接收推送、执行课程页面跳转、展示完成结果。

**职责边界：**
- 提供任务创建界面
- 建立 WS 连接并接收推送
- 执行路由跳转
- 上报打开成功和学习完成

**不负责：**
- 不负责任务调度
- 不负责自己决定定时触发

---

### 3.8 小程序

**定义：**
家长端小程序管理端，作为另一种任务接入与展示终端。

**职责边界：**
- 与 Vue3 共享同一套任务定义
- 接收同一套 WS / HTTP 回执协议
- 支持创建与查看学习任务和状态

**不负责：**
- 不负责调度逻辑
- 不负责后端任务状态机

---

### 3.9 学习页面

**定义：**
孩子实际进入并完成练习的页面，例如诗歌练习、口算练习等。

**职责边界：**
- 接收跳转参数
- 展示课程内容
- 记录学习完成结果

**不负责：**
- 不负责定时调度
- 不负责任务创建

---

### 3.10 幂等 ID（op_id）

**定义：**
每次定时任务触发生成的唯一标识，用于串联“触发—推送—打开—完成”的整条链路。

**职责边界：**
- 作为一次执行的唯一主键
- 用于去重、重试与状态追踪

**不负责：**
- 不承载业务含义
- 不替代任务 ID

---

## 4. 总体架构

系统建议分为四条主链路：

### 4.1 家长输入链路
家长通过 Vue3、小程序或语音输入创建任务。语音先经 ASR 转文本，再经语义结构化形成标准任务对象。

### 4.2 调度链路
任务对象进入业务后端后，业务后端调用 OpenClaw 的 cron/job 接口创建定时任务。到点后由 OpenClaw cron 触发 agent loop。

### 4.3 动作编排链路
OpenClaw agent loop 调用 FastMCP 工具。FastMCP 将任务翻译成内部 JSON，并发送到业务方自建 WS 网关。

### 4.4 实时推送链路
WS 网关将消息推送给 Vue3 或小程序前端。前端收到后执行页面跳转，并回传 ack。学习完成后再回传完成态，业务后端写库。

## 5. 组件职责表

| 组件 | 主要职责 | 主要输入 | 主要输出 | 不负责 |
|---|---|---|---|---|
| ASR | 语音转文本 | 音频流 | 文字结果 | 业务判断 |
| 语义结构化 | 文本转任务参数 | 文本 | 结构化 JSON | 任务执行 |
| 业务后端 | 统一 API、状态管理、落库 | 结构化任务 | 任务记录、状态 | 页面跳转 |
| OpenClaw Cron | 定时触发 | 定时任务 | agent 触发 | 前端连接 |
| OpenClaw Agent Loop | 单次执行编排 | 触发任务 | 工具调用结果 | WS 分发 |
| FastMCP | 工具出口 | 编排指令 | 内部 JSON 消息 | 长连接管理 |
| WS 网关 | 实时消息推送 | 内部 JSON | 前端事件 | 任务调度 |
| Vue3 / 小程序 | 展示与交互 | 推送消息 | ack / 完成回执 | 定时器 |

## 6. 任务状态机

建议将单次定时学习任务定义为以下状态：

- `draft`：任务已生成但尚未保存
- `scheduled`：已创建定时任务
- `triggered`：到点触发，agent 已启动
- `pushed`：已推送到前端会话
- `opened`：前端已打开学习页面
- `completed`：学习已完成并成功写回
- `failed`：执行失败
- `timeout`：触发后超时未完成

### 状态边界说明

- `scheduled -> triggered`：由 OpenClaw cron 完成
- `triggered -> pushed`：由 FastMCP + WS 推送层完成
- `pushed -> opened`：由前端 ack 完成
- `opened -> completed`：由学习页完成后回写完成
- 任意状态 -> `failed`：出现不可恢复错误
- 任意状态 -> `timeout`：超过设定时限未完成

## 7. 核心时序

### 7.1 语音创建定时任务

1. 家长在 Vue3 或小程序中发出语音。
2. ASR 将音频转成文本。
3. 语义结构化服务提取任务字段。
4. 业务后端生成任务并调用 OpenClaw REST 接口创建 cron job。
5. OpenClaw 持久化任务并等待触发。

### 7.2 定时触发并打开页面

1. 到点后，OpenClaw cron 唤醒 agent loop。
2. agent loop 调用 FastMCP 工具。
3. FastMCP 工具向 WS 网关发送内部 JSON。
4. WS 网关把 `open_page` 消息推到前端。
5. 前端执行路由跳转。
6. 前端返回 `opened` ack。

### 7.3 学习完成回写

1. 用户完成练习。
2. 学习页面向业务后端发送完成回调。
3. 后端更新学习记录与打卡状态。
4. 如需要，再通知家长端显示完成结果。

## 8. 内部消息协议

### 8.1 打开课程页消息

```json
{
  "type": "open_page",
  "op_id": "cron-20260602-183000-001",
  "child_id": "child_001",
  "course_type": "oral_arithmetic",
  "title": "口算练习",
  "route": "/learn/arithmetic/lesson-12",
  "deadline_ms": 3000,
  "source": "openclaw_cron"
}
```

**字段说明：**
- `type`：消息类型
- `op_id`：本次执行的幂等 ID
- `child_id`：目标孩子 ID
- `course_type`：课程类型
- `title`：页面标题
- `route`：前端路由
- `deadline_ms`：推送等待时限
- `source`：消息来源

### 8.2 页面已打开回执

```json
{
  "type": "ack",
  "op_id": "cron-20260602-183000-001",
  "status": "opened",
  "client": "vue3",
  "ts": 1717320000123
}
```

### 8.3 学习完成回执

```json
{
  "type": "learning_done",
  "op_id": "cron-20260602-183000-001",
  "status": "completed",
  "score": 95,
  "duration_sec": 420
}
```

### 8.4 失败消息

```json
{
  "type": "task_failed",
  "op_id": "cron-20260602-183000-001",
  "reason": "no_active_ws_session",
  "retryable": true
}
```

## 9. 接口边界建议

### 9.1 家长端 API
建议统一由业务后端提供，不让前端直接接触 OpenClaw。

- `POST /api/learning/tasks`：创建任务
- `GET /api/learning/tasks/{id}`：查询任务
- `POST /api/learning/tasks/{id}/pause`：暂停
- `POST /api/learning/tasks/{id}/resume`：恢复
- `POST /api/learning/tasks/{id}/cancel`：取消

### 9.2 WS 网关接口
WS 网关只接收结构化内部消息，不接收自然语言。

- `open_page`
- `ack`
- `learning_done`
- `task_failed`

### 9.3 OpenClaw 接口
OpenClaw 仅作为调度层使用，由业务后端通过 REST 接口创建 cron/job。

## 10. 可靠性设计

### 10.1 幂等
每次任务触发都必须生成唯一 `op_id`，所有后续消息都带同一个 `op_id`。

### 10.2 重试
仅对“未收到 ack”的消息进行重试，避免重复打开学习页面。

### 10.3 离线补偿
如果目标设备离线，WS 网关应记录待投递任务，待客户端重新上线后补发。

### 10.4 超时处理
如果一定时间内前端未回 `opened`，任务应标记为 `timeout` 或 `failed`。

### 10.5 多端在线
同一孩子可能同时登录 Vue3 和小程序，需要定义主设备优先级或广播策略。

- 完成打卡闭环

## 13. 总结

本方案的核心边界非常清楚：

- **OpenClaw** 负责“什么时候执行”
- **FastMCP** 负责“执行什么动作”
- **WebSocket 网关** 负责“把动作实时送到前端”
- **业务后端** 负责“记录什么状态、写回什么结果”
- **前端 / 小程序** 负责“展示与执行学习页面”

这样设计后，定时调度、实时推送、学习完成三条链路互不污染，系统更稳，也更容易扩展到新的课程类型。
