# AI陪伴机器人家长端小程序 PRD V1.0（14页版）

## 一、产品定位

### 产品名称

AI陪伴机器人 · 家长端

### 产品定位

一款面向3-12岁儿童家长的微信小程序。

家长可以：

- 实时查看孩子学习状态
- 查看机器人状态
- 查看成长数据
- 远程陪伴孩子
- 给孩子发布成长任务
- 查看成长报告

产品关键词：

**科技感 · 陪伴感 · 成长感 · 极简 · 高级感**

首页 → 使用时长

首页 → 行为分析

首页 → 派任务

我的 → 设备管理

我的 → 通知设置

我的 → 学习目标

设备管理 → 未绑定状态

首页 → 离线状态

所有按钮均建立点击交互，返回逻辑完整。

# 七、设计要求（给 Claude Code / Pencil MCP）

请参考我提供的 SmartTask 蓝色系 UI 风格图，整体采用现代科技蓝配色（#316AFD、#4075FF、#84A6FD），大圆角卡片（24px）、留白充足、轻阴影、高保真设计。所有页面需统一使用同一套 Design System、组件（Components）和颜色变量（Variables），采用 Auto Layout 构建，并建立完整的 Prototype 页面跳转，最终输出微信小程序尺寸（390×844）的高保真可交互原型。
