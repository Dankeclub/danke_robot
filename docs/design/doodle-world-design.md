# 涂鸦天地｜功能与交互设计文档

> **状态**：需求确认稿  
> **适用项目**：`car-screen-vue`  
> **页面基准**：固定横屏 `1024 × 600`  
> **草图导出规格**：白底 `512 × 512` PNG

## 1. 背景与目标

将首页的“问答百宝箱”替换为“涂鸦天地”。孩子可以在白色画板上自由画草图，使用画笔和橡皮局部修改；完成后选择生成风格，系统将草图 PNG 上传至业务后端，由后端转发给生图模型。生成期间显示轻松、有趣的过渡动画，完成后展示“我的草图”与“魔法作品”的对比结果，并支持单张图片放大查看。

### 1.1 核心目标

- 让孩子能在少量操作下完成一张涂鸦。
- 画笔、橡皮、清空操作语义明确，避免误删整张作品。
- 生成并上传标准白底 `512 × 512` PNG。
- 不在前端暴露任何生图模型密钥；由业务后端转发与管理任务。
- 支持生成前、生成中、生成成功、生成失败的完整体验。

### 1.2 MVP 范围

**本期包含：**

- 黑色画笔；
- 局部擦除的橡皮；
- 清空重画及二次确认；
- 收起/展开的浮动工具栏；
- 三种生图风格选择；
- 草图 PNG 导出、上传、生成轮询；
- 生成动画、失败重试；
- 草图与生成图对比、单张放大、下载/保存入口。

**本期不包含：**

- 多颜色画笔；
- 画笔粗细调节；
- 撤销/重做；
- 多张作品历史图库；
- 用户登录、云端作品管理；
- 前端直连第三方生图模型。

| 项目 | 内容 |

### 2.2 页面状态

涂鸦天地使用同一个页面容器，根据状态切换内容：

```text
drawing（创作）
  └─ 完成创作 → style-select（选择风格）
                     └─ 确认生成 → exporting（导出 PNG）
                                        └─ 上传成功 → generating（生成中）
                                                           ├─ 成功 → result（结果）
                                                           └─ 失败 → error（失败）
```

## 3. 创作页设计

### 3.1 尺寸与布局

页面整体保持 `1024 × 600`。中央是视觉显示为 `600 × 600` 的正方形白色画板，完整占据页面高度；操作区不占用画板上下空间。

```text
┌────────────────────────────────────────────────────────────────┐
│ ← 返回                                                          │
│                                                                  │
│             ┌──────────────────────────┐    ┌──────────────┐   │
│             │                          │    │ ✏️ 画笔       │   │
│             │                          │    │ ◯ 橡皮       │   │
│             │       白色画板            │    │ ↻ 清空重画   │   │
│             │        600 × 600          │    │ ✨ 完成创作  │   │
│             │                          │    └──────────────┘   │
│             │                          │        [工具收起]      │
│             └──────────────────────────┘                        │
└────────────────────────────────────────────────────────────────┘
```

- 画板默认居中，四周留出的横向空间用于返回、标题、提示和浮动工具。
- 画板为纯白色、深色手绘边框，内部不叠加纸张纹理或 SVG 扭曲滤镜，避免影响笔迹可读性。
- 工具栏位于画板右侧，展开和收起不会改变画板的尺寸或位置。
- 工具栏收起后只保留一个不遮挡画板的“工具”浮动标签；点击该标签可再次展开。

### 3.2 工具与行为

| 控件 | 默认状态 | 行为 |
| --- | --- | --- |
| 画笔 | 默认选中 | 用黑色、圆头、固定粗细绘制笔迹。 |
| 橡皮 | 未选中 | 仅擦除手指/鼠标经过的笔迹区域，不清空整张画。 |
| 清空重画 | 始终可用 | 弹出确认层；确认后删除全部笔迹并回到画笔模式。 |
| 完成创作 | 有笔迹时可用 | 进入风格选择；无笔迹时提示“先画点什么吧～”。 |
| 工具收起 | 可用 | 收起完整工具栏，仅留下“工具”入口。 |

### 3.3 橡皮规则

橡皮必须是**局部擦除**：

- 橡皮划过的位置变回白纸，不影响未经过的笔迹；
- 橡皮尺寸可大于画笔尺寸，便于儿童操作；
- 使用圆形半透明光标或圆形提示反馈当前擦除范围；
- 只有“清空重画”才会删除整张画。

### 3.4 防误触规则

点击“清空重画”时显示确认层：

```text
要把这张画全部擦掉吗？

[继续画]  [清空]
```

- 点击“继续画”：关闭确认层，不改变笔迹；
- 点击“清空”：清除全部笔迹，回到画笔模式；
- “完成创作”不应在空画板上提交。

## 4. 风格选择与生成过渡

### 4.1 风格选择

在孩子点击“完成创作”后显示风格选择层，不在画画前打断创作。

| 风格 ID | 显示名称 | 建议提示词方向 |
| --- | --- | --- |
| `storybook` | 童话插画（默认） | 明亮、温暖、童趣的绘本插画。 |
| `toy3d` | 3D 玩具 | 圆润、可爱的 3D 玩具模型质感。 |
| `watercolor` | 水彩绘本 | 柔和水彩、童书纸张质感。 |

确认后立即执行 PNG 导出与后端上传。

### 4.2 生成中过渡动画

生成过程中使用循环动画和儿童化文案，避免展示复杂技术细节：

```text
你的画正在变成魔法作品……

草图卡片 → 星星粒子 → 成品卡片
蛋仔正在帮你施展魔法～
```

可轮换的进度文案：

- 正在认识你的涂鸦…
- 正在给画面加上颜色…
- 马上就要完成啦…

过渡动画持续至后端任务完成或失败，不使用固定时长假完成。

## 5. 结果页与放大查看

### 5.1 对比结果

生成成功后展示两个并排的正方形卡片：

```text
┌────────────────┐      →      ┌────────────────┐
│                │             │                │
│   我的草图      │             │   魔法作品      │
│                │             │                │
└────────────────┘             └────────────────┘
      点击放大                        点击放大
```

- 左侧显示本次导出的本地草图 PNG；
- 右侧显示后端返回的生成图；
- 两张图均按 `object-fit: contain` 展示，保持完整正方形画面；
- 底部提供“再画一张”和“保存作品”操作。

### 5.2 放大预览

点击草图或生成图后打开模态预览层：

- 只展示被点击的单张图片；
- 提供关闭按钮；
- 提供保存/下载按钮；
- 点击遮罩区域也可关闭；
- 预览层层级高于宠物、装饰和普通按钮。

## 6. Canvas 技术方案

### 6.1 实现原则

使用浏览器原生 Canvas 2D API，不引入额外画板依赖。当前项目基于 Vue 3 + Vite 5，面向现代 Chromium/Safari/WebView，原生 Canvas、Pointer Events、`canvas.toBlob()` 可以满足 MVP。

### 6.2 输入与坐标

使用 Pointer Events 统一处理鼠标、触控板和触摸屏输入：

```text
pointerdown  → 开始一笔并捕获 pointer
pointermove  → 追加轨迹点并实时渲染
pointerup    → 结束本笔
pointercancel → 安全结束本笔
```

Canvas 必须设置：

```css
.doodle-canvas {
  touch-action: none;
}
```

原因：项目全局当前使用 `touch-action: auto`；若不覆盖，触摸屏绘画时可能触发页面滚动或浏览器手势。

每一笔保存为归一化轨迹，坐标范围是 `0~1`：

```js
{
  tool: 'pen', // 或 'eraser'
  width: 0.012,
  points: [
    { x: 0.25, y: 0.38 },
    { x: 0.26, y: 0.39 }
  ]
}
```

保存比例坐标而不是仅保存屏幕像素，能确保：

- 画板显示尺寸变化时笔迹不偏移；
- 可重新渲染；
- 可稳定导出为固定 `512 × 512` PNG；
- 后续可扩展撤销/重做。

### 6.3 画笔与橡皮渲染

- 画笔：`globalCompositeOperation = 'source-over'`；黑色、圆头、圆角连接；
- 橡皮：`globalCompositeOperation = 'destination-out'`；只擦除经过区域；
- 显示画布可以保持透明，外层画板显示白底；
- 不要将全局 `.card-sketch` 的 SVG 手绘滤镜加到 Canvas 本身，滤镜仅用于外框。

### 6.4 PNG 导出

**导出目标固定为 `512 × 512`，PNG 格式、白色背景。**

导出时创建一个独立 Canvas：

1. 创建 `512 × 512` 离屏 Canvas；
2. 用 `#FFFFFF` 填满背景；
3. 根据归一化轨迹将笔迹重绘到离屏 Canvas；
4. 通过 `toBlob('image/png')` 得到 Blob；
5. 使用 `File` 封装为 `doodle.png` 并上传。

伪代码：

```js
const exportCanvas = document.createElement('canvas')
exportCanvas.width = 512
exportCanvas.height = 512

const ctx = exportCanvas.getContext('2d')
ctx.fillStyle = '#FFFFFF'
ctx.fillRect(0, 0, 512, 512)
renderStrokes(ctx, strokes, 512, 512)

exportCanvas.toBlob((blob) => {
  const image = new File([blob], 'doodle.png', { type: 'image/png' })
  upload(image)
}, 'image/png')
```

使用 Blob/File 而不是 Base64：

- 文件体积更小；
- 可直接写入 `FormData`；
- 减少浏览器内存占用；
- 避免 Base64 编码产生的额外体积。

### 6.5 跨域限制

草图导出 Canvas 只渲染本地轨迹，不绘制远程生成图。远程图片若没有正确 CORS 响应头，绘制到 Canvas 后会导致 Canvas 无法导出。

因此：

- 草图：本地 Canvas → PNG Blob；
- 生成图：普通 `<img>` 显示；
- 下载生成图：由后端提供可下载 URL、图片代理，或设置合适的下载响应头。

## 7. 后端接口约定

生图服务必须经业务后端转发，前端不保存模型密钥。

### 7.1 创建任务

```text
POST /api/doodle/generate
Content-Type: multipart/form-data
```

请求字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `image` | File | 是 | 白底 `512 × 512` PNG，文件名 `doodle.png`。 |
| `style` | string | 是 | `storybook`、`toy3d`、`watercolor` 之一。 |
| `width` | number | 是 | `512`。 |
| `height` | number | 是 | `512`。 |

推荐响应：

```json
{
  "taskId": "task_123456"
}
```

### 7.2 查询任务

```text
GET /api/doodle/tasks/:taskId
```

推荐响应：

```json
{
  "status": "queued",
  "imageUrl": null,
  "message": null
}
```

状态值：

| 状态 | 前端行为 |
| --- | --- |
| `queued` / `generating` | 持续显示过渡动画，并轮询。 |
| `succeeded` | 进入结果页，读取 `imageUrl`。 |
| `failed` | 进入失败状态，展示 `message` 与重试按钮。 |

建议轮询间隔为 2 秒，超过约 90 秒提示生成时间较长，并允许孩子继续等待或返回画板。

### 7.3 开发环境代理

待后端地址确认后，开发期通过 Vite 的 `/api` 代理转发，避免浏览器跨域问题。生产环境则建议前端与业务后端同域部署，或由网关统一转发 `/api`。

## 8. 错误与恢复

| 场景 | 用户提示 | 可用操作 |
| --- | --- | --- |
| 空白画板点击完成 | 先画点什么吧～ | 返回画板。 |
| PNG 导出失败 | 这张画暂时没保存好，再试一次吧 | 重新尝试导出。 |
| 上传失败 | 魔法暂时没连上，再试一次吧 | 重试上传、返回画板。 |
| 模型任务失败 | 这次魔法没有成功，我们再试一次吧 | 重新生成、返回画板。 |
| 任务超时 | 还在努力创作中，要继续等一会儿吗？ | 继续等待、返回画板。 |

返回画板时默认保留当前轨迹，避免网络错误造成孩子作品丢失。
