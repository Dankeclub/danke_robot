├── Toast「任务已发送」自动出现
├── [Toast 2s 后消失]
└── 用户可继续操作（切换 Tab、修改勾选）

状态流转图：
─────────────────────────────────────────────────────

    ↑                                      │
    └──────── 关闭后重新打开 ──────────────┘

## 四、Prototype 交互规范

| 属性 | 建议值 |
|------|--------|
| **Trigger** | On Click（主要）/ On Drag（摇杆、滑块） |
| **Action** | Navigate To（页面跳转）/ Overlay Open（弹窗/Bottom Sheet）/ Switch To（Tab 切换）/ Back（返回） |
| **Animation** | Push（页面跳转，从左滑入）/ Cover（Bottom Sheet，从下滑入）/ Dissolve（Dialog，淡入） |
| **Duration** | 页面跳转 300ms / 弹窗 250ms / Tab 切换 150ms |
| **Easing** | Ease Out（入场）/ Ease In（退场） |
| **Back 逻辑** | ← 返回 = Navigate Back（Pop）/ Dialog/Sheet = Close Overlay |

### 交互分类

| 类别 | 触发 | 动作 | 动画 | 时长 |
|------|------|------|------|------|
| Tab 切换 | On Click | Switch To | None / Dissolve | 150ms |
| 子页面跳转 | On Click | Navigate To | Push (left) | 300ms |
| 返回 | On Click | Navigate Back | Push (right) | 300ms |
| Bottom Sheet 弹出 | On Click | Overlay Open | Cover (up) | 250ms |
| Bottom Sheet 关闭 | On Click (✕) | Overlay Close | Cover (down) | 250ms |
| Dialog 弹出 | On Click | Overlay Open | Dissolve | 200ms |
| Dialog 关闭 | On Click (取消/蒙层) | Overlay Close | Dissolve | 200ms |
| Toast 提示 | Auto | Show | Fade In → Fade Out | 2000ms 后消失 |
| 状态切换 Tab | On Click | Switch To | None | 150ms |
| 开关 Toggle | On Click | State Change | None | 0ms |

全部页面有出口（返回箭头 / Tab 切换 / 按钮跳转），无死胡同。

全部页面有入口来源。无孤立页面。

无死循环。关键路径均为有向无环：
- P13 → P13r → P01（单向）
- P14 → P18 → P14s → P01（单向）
