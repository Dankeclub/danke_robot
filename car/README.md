# 🚗 小车端 — 边缘端模块

所有运行在小车硬件上的代码都在这里。

## 硬件对照

```text
                    ┌──────────────────────────────┐
                    │      SC171 V3 智能模组         │
                    │  8×Cortex@2.7GHz  13 TOPS NPU │
                    │  8GB RAM  128GB 存储           │
                    │                              │
                    │  ┌────────────────────────┐   │
                    │  │  behavioral/ 🧠        │   │
                    │  │  行为检测 (端侧推理)     │   │
                    │  │  MediaPipe + YOLOv8     │   │
                    │  └────────────────────────┘   │
                    │  ┌────────────────────────┐   │
                    │  │  screen/ 🖥️            │   │
                    │  │  车载触摸屏 (HDMI)       │   │
                    │  │  Vue 3 · 1024×600      │   │
                    │  └────────────────────────┘   │
                    │  ┌────────────────────────┐   │
                    │  │  motion-control/ 🔧    │   │
                    │  │  运动控制 · GPIO        │   │
                    │  │  麦轮底盘 · WebSocket    │   │
                    │  └────────────────────────┘   │
                    └──────────────┬───────────────┘
                                   │
              ┌────────────────────┴────────────────────┐
              │        树莓派 (Raspberry Pi)              │
              │                                         │
              │  ┌──────────────────────────────────┐   │
              │  │  vision/ 👁️                      │   │
              │  │  YOLOv8 人体检测 + 姿态识别        │   │
              │  │  通过 RTSP 供 behavioral 消费      │   │
              │  └──────────────────────────────────┘   │
              └─────────────────────────────────────────┘
```

## 模块说明

| 模块 | 运行位置 | 作用 | 对外接口 |
|------|----------|------|----------|
| `screen/` | SC171 (HDMI 屏) | 儿童学习交互界面，6 种学习模式 | 无（纯前端） |
| `behavioral/` | SC171 (NPU) | 实时行为感知：坐姿/专注/看书/玩游戏/看电视/走神 | WebSocket → 云端 |
| `vision/` | 树莓派 | 人体检测 + MediaPipe 姿态识别 | RTSP 视频流 → behavioral |
| `motion-control/v1.0/` | SC171 (GPIO) | 麦轮底盘运动控制 v1 | WebSocket |
| `motion-control/v2.0/` | SC171 (GPIO) | 麦轮底盘运动控制 v2 | WebSocket |

## 数据流向

```text
摄像头 ──RTSP──▶ vision/ ──人体框──▶ behavioral/ ──行为事件──▶ cloud/backend/
                                    │
                                    ├── 行为提醒 ──▶ screen/ (UI 反馈)
                                    │
                                    └── 跟随指令 ──▶ motion-control/ (底盘动作)
```
